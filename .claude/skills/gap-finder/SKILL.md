# gap-finder

`data/atoms.csv` と `docs/themes/` の現状を比較し、**未カバーの頻出論点**を優先度順に列挙する。週次レビュー用。書き直しは行わない（分析・報告のみ）。

---

## 使い方

```
/gap-finder
/gap-finder --field 配電          （特定分野に絞る）
/gap-finder --top 10              （上位N件だけ表示）
```

---

## 事前に必ず読むファイル

1. `data/atoms.csv` — 全行（登録済みの公式・過去問・落とし穴の一覧）
2. `docs/kakomon/by-field.md` — 分野別の**全**過去問リスト（出題数・難易度）
3. `docs/themes/index.md` — テーマ一覧（存在するページの確認）
4. `data/pipeline.csv` — 各 draft の status（pending / writing / review / done）
5. `docs/themes/` 配下の全 .md ファイルのフロントマター（tags・version）

---

## 分析手順

### ステップ1: テーマカバレッジの確認

`docs/themes/` の全ファイルを一覧し、存在するテーマを列挙する。
`by-field.md` のセクション見出し（分野名）と突き合わせて、**ページが存在しない分野**を抽出する。

### ステップ2: 過去問カバレッジの確認

`by-field.md` の全問（年度 × 問番号）と `data/atoms.csv` の kakomon 行を突き合わせる。
`atoms.csv` に登録されていない過去問を「未登録」としてリストアップする。

### ステップ3: 公式カバレッジの確認

`by-field.md` の計算問題（問題タイプ=計算）のうち、対応する `formula` 行が `atoms.csv` に存在しないものを「公式未登録」としてリストアップする。

### ステップ4: 優先度スコアの算出

各ギャップに対して優先度スコアを算出する：

```
スコア = 出題数 × 難易度係数 × ステータス係数

難易度係数:
  ★☆☆☆☆ = 1.0
  ★★☆☆☆ = 1.2
  ★★★☆☆ = 1.5
  ★★★★☆ = 1.8
  ★★★★★ = 2.0
  — (不明) = 1.0

ステータス係数:
  ページなし = 3.0
  pending = 2.0
  writing = 1.5
  review = 1.2
  done = 0.0  （スキップ）
```

## 禁止事項

- ファイルを書き直さない・追記しない（報告のみ）
- `by-field.md` に記載のない分野を「頻出」と判定しない
- スコアが低い項目を「不要」と判断しない（ユーザーが優先度を決める）

---

## 連携

- 最優先ギャップへのアクションは次のスキルで実行する：
  - ページなし → `/theme-writer <テーマ名>`
  - 公式未登録 → `/formula-ingest <公式名>`
  - 過去問未登録 → `/kakomon-ingest <年度> <問番号>`
- レポート後、`data/pipeline.csv` の pending 行を確認して着手順を決める
