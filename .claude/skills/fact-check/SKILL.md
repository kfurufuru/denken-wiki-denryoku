# fact-check

`docs/themes/` または `docs/reference/` の Markdown ファイルを検査し、**数値・単位・公式の誤り・未確認箇所**を指摘リストとして出力する。書き直しは行わない（指摘のみ）。

---

## 使い方

```
/fact-check <ファイルパス>
例: /fact-check docs/themes/haiden.md
例: /fact-check docs/reference/calc-patterns.md
```

差分（git diff）を渡すことも可能：
```
/fact-check --diff   （ステージ済み変更を対象にする）
```

---

## 事前に必ず読むファイル（照合基準）

| ファイル | 照合対象 |
|----------|---------|
| `docs/reference/numbers.md` | 数値（落差・電圧区分・係数・パーセント値） |
| `docs/reference/glossary.md` | 用語の正確な表記・定義 |
| `docs/reference/calc-patterns.md` | 計算式の形・変数名・単位 |

対象ファイル自体も最初に全文を読む。

---

## 検査項目

### A. 数値チェック
`numbers.md` と突き合わせ、以下を検出する：

- 係数の誤り（例: `9.81` を使っている → 正: `9.8`）
- 電圧区分の境界値の誤り（例: 低圧の上限を `600 V` 以外で書いている）
- 水車適用落差の誤り（例: ペルトンの下限を `200 m` と書いている → 正: `300 m`）
- パーセント・小数の混用（例: 効率を `85` と書いて `%` を付けていない）

### B. 単位チェック
- 電力: `kW`（`W` や `MW` の文脈ミス）
- 流量: `m³/s`（`m3/s` の表記揺れも指摘）
- 落差・距離: `m`
- 電圧: `V` または `kV`（桁のミス）
- 角周波数 ω と周波数 f の混用
- `p.u.`（単位法）と実値の混在

### C. 公式チェック
`calc-patterns.md` の式と照合：

- 変数名の不一致（例: 有効落差を `h` と書いている → 正: `H`）
- 式の変形ミス（例: `P = 9.8 × H × Q × η` の掛け算の順番は無関係だが、`P = 9.8 / QHη` のような誤変形）
- 熱効率式の分母・分子の取り違え
- 電圧降下式で `r cosθ + x sinθ` が `r sinθ + x cosθ` になっている

### D. 用語チェック
`glossary.md` と照合：

- 「有効落差」を「実際の落差」「使用落差」などと書いていないか
- 「調速機」と「ガバナー」の表記揺れ（統一されているか）
- 「衝動水車」「反動水車」の誤分類
- カタカナ用語の揺れ（例: コンバインドサイクル vs コンバインド・サイクル）

### E. 確認ステータスチェック
- `✅ 確認済み` が付いているのに A〜D で指摘が出た場合 → 必ず警告
- 数値・公式を含むセクションに確認ステータスが無い場合 → `⚠️ 未確認` 推奨を出力

## 出力フォーマット

```
## fact-check 結果: docs/themes/haiden.md

### 指摘事項（X 件）

| # | 行番号 | 種別 | 内容 | 照合元 |
|---|--------|------|------|--------|
| 1 | L42 | 数値 | 係数が `9.81` → 正: `9.8` | numbers.md |
| 2 | L78 | 単位 | 流量の単位が `m3/s` → 正: `m³/s` | — |
| 3 | L103 | 公式 | 電圧降下式の sinθ と cosθ が逆 | calc-patterns.md パターン3 |

### 要確認（照合基準なし）

| # | 行番号 | 内容 |
|---|--------|------|
| 1 | L156 | 変圧器の無負荷損失の数値（5%）— numbers.md に記載なし。参考書で要確認 |

### ✅ ステータス判定
- 現状: ⚠️ 未確認
- 指摘 0 件 + 要確認 0 件になれば ✅ に変更可
```

指摘が 0 件の場合：
```
## fact-check 結果: docs/themes/xxx.md
指摘事項: なし
照合基準にない数値・用語: なし
→ ✅ に変更可能
```

---

## 禁止事項

- ファイルを**書き直さない**（指摘と修正案の提示のみ）
- `✅` を自動で付与しない（ユーザーが目視確認してから手動で変更）
- `numbers.md`・`glossary.md` に記載のない事項を「誤り」と断定しない（「要確認」扱いにする）

---

## 連携

fact-check が完了したら：

1. 指摘を全件修正する
2. `data/atoms.csv` に新たな pitfall があれば `kakomon-ingest` または直接追記する
3. `data/pipeline.csv` の該当行を `status=review` → `status=done` に更新する
