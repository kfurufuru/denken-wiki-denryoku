# theme-writer

電力Wiki の `docs/themes/` に新規テーマページを生成する、または既存ページの不足セクションを補完する。

---

## 使い方

```
/theme-writer <テーマ名>
例: /theme-writer 配電線路
例: /theme-writer 変圧器 --section 落とし穴
```

---

## 事前に必ず読むファイル

1. `docs/themes/suiryoku.md` — 黄金テンプレート。構造・文体・粒度の基準
2. `docs/kakomon/by-field.md` — 対象テーマの出題数・出題タイプ・難易度分布を確認
3. `docs/reference/calc-patterns.md` — 対象テーマに関連する計算パターンを確認
4. `docs/reference/numbers.md` — 使う数値の正確な値を確認
5. `docs/reference/glossary.md` — 用語の正確な表記を確認
6. `data/atoms.csv` — 対象テーマの atoms（type=formula / kakomon / pitfall）を抽出

---

## 出力仕様

### ファイル名
`docs/themes/<テーマ名をローマ字スネークケース>.md`

例: 配電線路 → `haiden.md`（既に存在する場合は上書き前に差分確認を求める）

### フロントマター
```yaml
---
tags: [分野, サブテーマ, 高頻度 or 中頻度 or 低頻度]
difficulty: ★☆☆ 〜 ★★★★★（by-field.md の多数決で判定）
version: v0.1
related_themes: [関連テーマ名（themes/ 内の既存ページ名）]
---
```

### 必須セクション（この順番で出力）

#### 1. ページタイトルと本質1行
```markdown
# ⚡ テーマ名

> 本質を1文で。何を何に変換するか、または何を計算するか。

!!! info "📋 vX.X — 確認ステータス"
    新規生成。公式・数値は参考書で必ず確認してください。⚠️
```

#### 2. 🧠 直感的理解
- 「なぜその設備が存在するか」を1〜2段落
- 他の概念（水力、電気回路など）へのアナロジーを1つ
- `!!! tip "5秒で思い出す"` で主要公式または暗記フレーズを ==ハイライト==

#### 3. 🏭 設備を歩く
- `graph LR` の Mermaid で設備フロー（5〜10ノード）
- 主要機器テーブル: `機器名 | 役割 | 試験で問われるポイント`
- `!!! note "現場の視点"` で実務・系統との関係を1段落

#### 4. ⚖️ 比較表
- 類似設備・方式の違いを表で整理（最低2列×4行以上）
- テーマによっては複数の比較表を並べる

#### 5. 🔍 主要公式
各公式について以下のセットを繰り返す：
```markdown
### 公式名

\```
数式（文字式）
\```

| 記号 | 意味 | 単位 |
|------|------|------|

#### 手順
1. ...

!!! danger "落とし穴"
    - ...

#### 例題
> 問題文
>
> 解: ...
```

`calc-patterns.md` に既存パターンがある場合はリンクのみ（重複記載しない）：
```markdown
→ [パターンX: ○○計算](../reference/calc-patterns.md#パターンX)
```

#### 6. 🕳️ 落とし穴・頻出ミス
- `by-field.md` の難問（★★★★以上）から逆算して抽出
- `data/atoms.csv` の `type=pitfall` も取り込む
- 箇条書き、1項目1〜3行

#### 7. 📊 過去問出題実績
`by-field.md` から対象テーマの行を転記（年度 / 問番号 / タイトル / タイプ / 難易度）

```markdown
| 年度 | 問 | タイトル | タイプ | 難易度 |
|------|---|---------|--------|--------|
```

出題数の合計を冒頭に明記：`（全X問、H18〜R07）`

#### 8. ⚡ 5秒で思い出す（速攻暗記）
- 主要公式を ==ハイライト== で3個以内
- 数値の境界値や係数の暗記フレーズ
- `📝 正誤判定の急所` を2〜3個

#### 9. フッター
```markdown
---

*vX.X — ⚠️ 未確認。公式・数値は参考書で照合後に ✅ に変更すること*
```

---

## 禁止事項

- 参考書・`numbers.md`・`glossary.md` で確認できない数値を書かない
- `✅ 確認済み` を付けない（新規生成は必ず `⚠️ 未確認`）
- 既存の絵文字マーカーを増やさない
- `docs/themes/` 以外のパスに書かない
- `calc-patterns.md` と重複する計算手順をフルで書かない（リンクで代替）

---

## 生成後の確認チェックリスト

生成後、`fact-check` スキルを実行すること：

```
/fact-check docs/themes/<生成ファイル名>.md
```

`fact-check` の指摘を全件解消してから `data/pipeline.csv` の status を `review` → `done` に更新する。
