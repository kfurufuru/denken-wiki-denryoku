# 引っかけパターン集

電力科目で頻出する引っかけパターンを因果説明付きでまとめる。
「なぜ間違いか」を理解することで、同じ誤答を構造的に潰す。

> 棲み分け: 本ページは**因果の理解**用。試験直前の高速確認は [試験直前3日チェックリスト](last-3days-checklist.md)、計算テンプレートは [B問題得点戦略](b-mondai-strategy.md) を参照。

## 操作・手順系

!!! warning "パターン1：DS操作時に電流が流れていると誤答"
    **誤答**: 「断路器（DS）で負荷電流を開放できる」
    **理由**: DSはアーク消弧機能を持たない。負荷電流が流れた状態でDSを開放すると
    アークが継続・拡大し、絶縁破壊や事故に至る。
    **正解**: 電流の開閉は必ず遮断器（CB）で行う。DSは電流ゼロの状態でのみ操作可能。

!!! warning "パターン2：投入・開放の操作順序の逆転"
    **誤答**: 「投入時はCB→DS、開放時はDS→CB」
    **理由**: 「CBで電流を制御し、DSは電流ゼロ時のみ」が原則。
    - 投入: DS先投入（電流未流通）→ CB投入（電流を流す）
    - 開放: CB開放（電流を切る）→ DS開放（電流ゼロ状態で分離）
    **正解**: 投入は DS → CB、開放は CB → DS。

!!! warning "パターン3：変圧器並行運転の負荷分担方向"
    **誤答**: 「%インピーダンスが大きい変圧器の方が多くの負荷を分担する」
    **理由**: 並列回路の原理より、インピーダンスが小さい経路に電流が多く流れる。
    変圧器も同じく %Z が小さい方に電流が集中する。
    容量の大きな変圧器に合わせて %Z を設計するため「大容量 = 小%Z」になることが多い。
    **正解**: 負荷分担比 =（定格容量 ÷ %Z）の比。**同一基準容量に換算した %Z 同士**なら容量が等しい場合に限り %Z_B : %Z_A（逆比）。容量が異なるときは自己容量基準%Zをそのまま逆比にすると誤答（例: A=100kVA/4%・B=200kVA/5% → 正しくは(100/4):(200/5)=5:8）

## 効率・エネルギー計算系

!!! warning "パターン4：揚水時と発電時のηの使い方逆転"
    **誤答**: 「揚水時の電力 P = 9.8QHη」（発電時と同じ式を使う）
    **理由**: エネルギーの流れる方向で η の扱いが変わる。
    - 発電時: 水のエネルギー → 電気（損失で減る） → P = 9.8QHη（掛ける）
    - 揚水時: 電気 → 水のエネルギー（損失分だけ余計に必要） → P = 9.8QH/η（割る）
    **正解**: 「欲しいエネルギーを得る側」はη掛け、「必要なエネルギーを供給する側」はη割り。

!!! warning "パターン5：変圧器銅損が負荷電流に比例すると誤答"
    **誤答**: 「銅損は負荷電流に比例する」
    **理由**: 銅損 = 3I²r（ジュール熱）。I²に比例するのが正しい。
    負荷が半分（I = 0.5 I_n）になると、銅損は 0.5² = 0.25 倍（1/4）になる。
    **正解**: 銅損 ∝ I²（電流の2乗に比例）。鉄損は負荷に無関係・一定。

!!! warning "パターン6：最大効率条件を「鉄損 + 銅損が最小」と混同"
    **誤答**: 「変圧器効率が最大になるのは合計損失がゼロのとき」
    **理由**: 損失ゼロは不可能。効率 η = P_out/(P_out + P_i + P_c) を最大化するには、
    出力あたりの損失（P_i/m + m·P_cn、mは負荷率）を最小化する。この2項の**積 P_i·P_cn は一定**なので、
    AM-GMより **P_i/m = m·P_cn（＝鉄損 = 銅損）** のとき和が最小＝効率最大。
    **正解**: 鉄損（一定）= 銅損（負荷の2乗に比例）のとき効率最大。

## 自然エネルギー系

!!! warning "パターン7：風力出力が風速の2乗に比例すると誤答"
    **誤答**: 「風力発電の出力は風速の2乗に比例する（P ∝ v²）」
    **理由**: 出力 = 運動エネルギー × 流量 = (½mv²) × (ρAv) ∝ v³。
    質量流量 m ∝ v なので、最終的に v² × v = v³ になる。
    **正解**: P ∝ v³。風速が2倍→出力は8倍（2³）。

!!! warning "パターン8：太陽電池の温度上昇で出力が上がると誤答"
    **誤答**: 「温度が上がると太陽電池の発電量が増える」
    **理由**: 太陽電池の開放電圧Voc は温度上昇で低下する（約 -0.4%/℃）。
    電流は温度上昇でわずかに増加するが、電圧低下の影響が支配的で出力（P=VI）は低下。
    夏に晴れていても、パネル自体の温度が高いと発電効率が下がる。
    **正解**: 温度上昇 → 開放電圧低下 → 最大出力低下。

## 送配電・電圧系

!!! warning "パターン9：フェランチ効果で送電端電圧が高いと誤答"
    **誤答**: 「フェランチ効果とは、送電端電圧が受電端電圧より高い現象」
    **理由**: フェランチ効果は「軽負荷時に受電端電圧が送電端電圧より**高く**なる」現象。
    充電電流（進み電流）が送電線のインダクタンスを通ることで電圧上昇が起きる。
    **正解**: フェランチ効果 → 受電端電圧 > 送電端電圧（逆転）。長距離・ケーブル系統で顕著。

!!! warning "パターン10：電圧降下式の係数（単相と三相の取り違え）"
    **誤答**: 「三相3線式の電圧降下 v = 2I(RcosΦ + XsinΦ)」
    **理由**: 係数「2」は単相2線式（往復2本分）のもの。
    三相は線電流1本分の電圧降下が相電圧降下であり、線間電圧に直すと √3 倍になる。
    **正解**: 三相3線式 → v = √3·I(RcosΦ + XsinΦ)、単相2線式 → v = 2I(RcosΦ + XsinΦ)

!!! warning "パターン11：電力損失の係数（3と√3の混同）"
    **誤答**: 「三相の電力損失 P_loss = √3·I²R」
    **理由**: 電力損失はジュール熱の物理量。3本の電線それぞれで I²R が発生する。
    合計は 3I²R。√3 は電圧計算（線電圧と相電圧の関係）に使うもので、損失には使わない。
    **正解**: P_loss = 3I²R

!!! warning "パターン12：受電端電力率と送電端力率の混同"
    **誤答**: 「送電線路の電力損失計算に受電端力率cosΦrを使う」と「送電端力率cosΦsを使う」の混乱
    **理由**: 一般に負荷（受電端）の力率が与えられることが多く、線電流IもP/(√3·Vr·cosΦr)で求める。
    問題文の「力率」がどこの点のものかを必ず確認する。
    **正解**: 問題文を読み、力率の基準点（送電端か受電端か）を最初に確認する。

## 機器特性系

!!! warning "パターン13：変圧器の巻数比と電圧・電流の方向"
    **誤答**: 「巻数が多い側の電圧が低い」
    **理由**: 変圧器は電圧が巻数に比例する（V1/V2 = N1/N2）。
    巻数が多い＝電圧が高い（昇圧側）。電流は逆比（N1/N2 = I2/I1）。
    **正解**: 電圧は巻数に比例、電流は巻数に反比例。

!!! warning "パターン14：コンデンサ（進み）と方向の混同"
    **誤答**: 「コンデンサは遅れ無効電力を供給する」
    **理由**: コンデンサは充放電により**進み電流**を流す → 進み無効電力（Q < 0 の補償）を供給。
    誘導性負荷（モーター等）が消費する遅れ無効電力を打ち消す効果がある。
    **正解**: コンデンサ → 進み無効電力を供給 → 力率改善（遅れ力率を1に近づける）。

!!! warning "パターン15：架空地線の役割を雷電流の導体と誤解"
    **誤答**: 「架空地線は雷電流を大地に流すためのもの」
    **理由**: 架空地線の主な役割は「遮蔽（直撃雷から電力線を守る）」と「誘導雷サージの低減」。
    雷撃を受けた際の電流は鉄塔を通して大地に流れるが、架空地線そのものが雷電流を「流す管」
    として機能するわけではない。架空地線がなければ電力線に直撃雷が当たる。
    **正解**: 架空地線の役割は「雷の直撃から電力線を保護する遮蔽」。逆フラッシオーバーには注意。

!!! warning "パターン16：電線の弛度（たるみ）と張力の関係"
    **誤答**: 「温度上昇→電線が伸びる→弛度が大きくなる→張力が大きくなる」
    **理由**: 電線が伸びると弛度（D = wS²/8T）は大きくなるが、張力Tは**下がる**。
    Dが増えるとTが減る（逆比関係）。また地絡故障の観点では弛度増大→地上高低下が問題。
    **正解**: 温度上昇 → 電線伸長 → 弛度増大 → 張力**低下**（張力と弛度は逆の関係）。

!!! warning "パターン17：中性点接地方式と地絡電流の大小"
    **誤答**: 「非接地方式では地絡電流が最大になる」
    **理由**: 非接地方式では1線地絡時の地絡電流は対地静電容量を通じた充電電流のみで小さい。
    直接接地方式の方が地絡電流が大きく（大地を経由する低抵抗ループが形成される）、
    これに対応した保護継電器の高速動作が必要。
    **正解**: 地絡電流の大小 → 直接接地 > 抵抗接地 > 非接地 > 消弧リアクトル接地（最小）。消弧リアクトルは対地静電容量の充電電流をL電流で打ち消すため地絡電流が最も小さい
