## Day 3（試験3日前）— 数値と公式の因果確認

### 水力発電の出力公式

!!! note "P = 9.8QHη の根拠"
    水の密度ρ = 1,000 kg/m³、重力加速度g = 9.8 m/s²。
    水の質量流量 = ρQ [kg/s]、位置エネルギー = mgh なので、
    理論水力 P₀ = ρgQH = 1,000 × 9.8 × Q × H [W] = 9.8QH [kW]。
    ηは水車・発電機の総合効率。9.8はρgを単位変換した係数であり、丸暗記ではなく物理量の積。

**確認事項**:

- [ ] Q[m³/s]、H[m]、η（小数）の単位を正しく代入できるか
- [ ] 「9.8はρgから導出される」と説明できるか
- [ ] 揚水時の所要電力 P = 9.8QH / η（ηで割る）と発電時（ηを掛ける）を混同しないか

### 電圧降下式

!!! note "単相と三相で係数が異なる理由"
    **単相2線式**: 往路・復路の2本分の抵抗・リアクタンスが直列に入るため、係数は2。
    `v = 2I(R cosΦ + X sinΦ)` [V]

    **三相3線式**: 線電流は1本分だが、線間電圧は相電圧の√3倍。
    `v = √3 · I(R cosΦ + X sinΦ)` [V]

    「なぜ√3か」— 三相の1線あたりの電圧降下は I(RcosΦ + XsinΦ) だが、
    これは相電圧の降下。線間電圧は √3 倍なので全体も √3 倍になる。

**確認事項**:

- [ ] 単相2線式の係数「2」の理由を説明できるか
- [ ] 三相3線式の係数「√3」の理由を説明できるか
- [ ] R・X・Φの定義（R=抵抗、X=リアクタンス、Φ=力率角）を言えるか

### 電力損失式

!!! note "P_loss = 3I²R のI²とその意味"
    3本の電線それぞれでジュール熱が発生する。1本あたりの損失は I²R。
    3本分の合計が 3I²R。

    **I²になる理由**: ジュール熱は電圧×電流 = (IR)×I = I²R。
    電圧に比例するのではなく、電流の2乗に比例する。これは銅損の本質。

**確認事項**:

- [ ] 「なぜ I² か」をオームの法則から導けるか
- [ ] 3線分あるのに係数「3」と、三相の√3の混同をしていないか

### 力率改善（コンデンサ進相）

!!! note "コンデンサで線電流が減る理由"
    有効電力P = √3 · V · I · cosΦ が一定のとき、cosΦが上がると I = P/(√3·V·cosΦ) は下がる。
    コンデンサは遅れ電流（誘導性負荷）に対して進み電流を供給し、
    電源から見た無効電流を相殺→合成電流（線電流）が減少する。

**確認事項**:

- [ ] コンデンサが「進み無効電力を供給する」ことを説明できるか
- [ ] 線電流が減ることで電圧降下・電力損失が同時に減る連鎖を説明できるか

## Day 2（試験2日前）— 引っかけパターン復習

### DS→CB操作順序

!!! warning "操作順序の誤りは最頻出引っかけ"
    **投入時**: DS（断路器）先投入 → CB（遮断器）後投入
    **開放時**: CB先開放 → DS後開放

    **理由**: DSはアーク消弧能力がない。負荷電流が流れている状態でDSを操作すると
    アークが発生し事故につながる。CBはアーク消弧機能を持つため、
    電流を切る操作は必ずCBで行う。

**確認事項**:

- [ ] 「DSはアーク消弧できない→電流ゼロの状態でのみ操作」を言えるか
- [ ] 投入・開放それぞれの手順を、理由とセットで説明できるか

### 揚水発電の効率方向

!!! warning "発電時と揚水時でηの使い方が逆"
    **発電時**: P_出力 = 9.8QHη（η掛け → エネルギーが減る方向）
    **揚水時**: P_入力 = 9.8QH / η（η割り → 入力エネルギーが増える方向）

    **理由**: 発電時は水のエネルギーから損失を引いて電気出力を得る（出力 < 理論値）。
    揚水時は必要な位置エネルギー以上のエネルギーを電力で投入しなければならない（入力 > 理論値）。

**確認事項**:

- [ ] 「入力=必要量/η、出力=投入量×η」という方向性を即答できるか

### 風力出力の風速指数

!!! warning "v²ではなくv³"
    風力発電の出力 P ∝ v³。

    **理由**: 風の運動エネルギー E = ½mv²。風量（単位時間あたりの空気質量）は m ∝ Av（断面積×風速）。
    よって P = E × 流量 ∝ v² × v = v³。

**確認事項**:

- [ ] 「質量流量がvに比例するため、指数が2から3になる」を説明できるか
- [ ] 風速が2倍になると出力は8倍（2³）になることを即答できるか

### 変圧器並行運転条件

!!! note "並行運転の3条件"
    1. **巻数比（変圧比）が等しい**: 異なると循環電流が流れ、無駄な損失が発生する
    2. **極性が等しい**: 異なると電圧が打ち消しあい短絡状態になる
    3. **百分率インピーダンスが等しい**: 異なると負荷分担が変圧器容量に比例しない

**確認事項**:

- [ ] 3条件それぞれの理由（満たさないと何が起きるか）を説明できるか
- [ ] 「容量に反比例して電流分担→インピーダンスが小さい方に過電流」を言えるか

## Day 1（試験前日）— B問題計算の最終確認

### 送電線路の計算手順

!!! note "電圧降下・電力損失の計算ステップ"
    1. 負荷電流 I を求める: I = P / (√3 · V · cosΦ)
    2. 電圧降下 v = √3 · I(RcosΦ + XsinΦ) を計算
    3. 電力損失 P_loss = 3I²R を計算
    4. 送電端電圧 Vs = Vr + v（受電端基準の場合）

    **ミスしやすい点**:
    - IはP[W]・V[V]で計算→[A]になっているか単位確認
    - sinΦ = √(1 - cos²Φ) を計算し忘れる
    - 受電端電圧Vrか送電端電圧Vsか問題文をよく読む

**確認事項**:

- [ ] 上記4ステップを見ずに再現できるか
- [ ] sinΦの計算を素早く行えるか（cos=0.8→sin=0.6、cos=0.6→sin=0.8）

### 変圧器効率の最大条件

!!! note "鉄損 = 銅損のとき効率最大になる数学的根拠"
    効率 η = P_out / (P_out + P_i + P_c)
    - P_i = 鉄損（負荷に無関係・一定）
    - P_c = 銅損（負荷電流Iの2乗に比例: P_c = P_c0 × (I/I_n)²）

    合計損失 P_i + P_c を最小化する問題。P_c = a（変数）とすると
    P_i + a の最小値は微分法より P_i = P_c のとき。
    これは「和が一定」ではなく「積が最小になる条件」— AM-GM不等式の応用。

**確認事項**:

- [ ] 「鉄損=銅損」が最小損失の必要条件であることを導けるか
- [ ] 最大効率時の負荷率 m = √(P_i / P_cn) を式から導けるか
