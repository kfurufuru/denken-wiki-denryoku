# B問題得点戦略

電力科目B問題（計算問題）の出題パターンと解法テンプレートをまとめる。
本ページの目的は「手が動く」レベルまでパターンを定着させること。

> 棲み分け: 本ページは**計算テンプレート**用。因果の理解は [引っかけパターン集](trap-patterns.md)、直前の高速確認は [試験直前3日チェックリスト](last-3days-checklist.md) を参照。

---

## B問題の基本構造

| 項目 | 内容 |
|------|------|
| 問題番号 | 問15〜問17（3問出題） |
| 解答数 | **3問すべて解答**（科目内の選択はない） |
| 各問配点 | 10点（小問a・bの2問構成） |
| B問題合計 | **30点** |
| 目標得点 | 18点（3問中1〜2問完答＋残りを部分点） |

!!! note "着手順の戦略"
    3問とも必答なので捨てられない。事前に「得意テーマから着手する」順番を決めておく。
    試験当日に悩む時間を消費しないことが重要。
    得意分野がない場合は、計算ステップ数が少ない問題から先に解いて得点を確保する。

## 最頻出テーマ別：出題傾向と配点

### 1位：配電線路（電圧降下・電力損失）

**出題頻度**: ほぼ毎年（R01〜R07の11回中10回。R06下のみ欠落）

**出題パターン**:

- 負荷が末端に集中している単純な系統
- 途中に分岐がある系統（合成抵抗・合成電流の計算）
- 力率改善前後の比較

**計算テンプレート**:

```
Step 1: 負荷電流を求める
        I = P / (√3 · V · cosΦ)    [三相の場合]
        I = P / (V · cosΦ)          [単相の場合]

Step 2: 電圧降下を求める
        v = √3 · I(R·cosΦ + X·sinΦ)  [三相3線式]
        v = 2I(R·cosΦ + X·sinΦ)      [単相2線式]

Step 3: 電力損失を求める
        P_loss = 3I²R               [三相]
        P_loss = 2I²R               [単相2線]

Step 4: 送電端電圧 or 受電端電圧を求める
        Vs = Vr + v  (受電端基準)
        Vr = Vs - v  (送電端基準)
```

!!! warning "よくある計算ミス"
    - sinΦの計算忘れ: cosΦ=0.8 → sinΦ=0.6、cosΦ=0.6 → sinΦ=0.8（3-4-5の直角三角形）
    - 抵抗Rの単位: [Ω/km]なら線路長[km]を掛けることを忘れない
    - 三相と単相の係数（√3 vs 2）を取り違える

---

### 2位：火力発電（熱効率・CO₂排出量計算）

**出題頻度**: B問題（問15〜17）の枠内で11回中6回。問2・問3などA問題側の計算まで含めると11回中9回（R02・R06上のみ欠落）と配電に次ぐ高頻度

**出題パターン**:

- 熱効率（発電端・送電端）の計算
- 燃料消費量から発電電力量を求める計算
- CO₂排出量の計算（炭素比・燃焼反応式）

**計算テンプレート**:

```
熱効率:  η = P・t / (B・H) × 100  [%]
  P: 出力 [kW]、t: 時間 [h]、B: 燃料消費量 [kg]、H: 発熱量 [kJ/kg]

燃料消費量:  B = P・t / (η・H)

CO₂排出量:  CO₂ = B × 炭素比 × 44/12
  ※ 44/12 は炭素(C)からCO₂への分子量換算係数
```

!!! warning "単位換算に注意"
    発熱量は [kJ/kg]・[MJ/kg] など問題によって単位が異なる。出力の [kW]・[kWh] との単位換算（1kWh = 3600kJ）を必ず確認する。

---

### 3位：水力発電（出力計算・揚水）

**出題頻度**: ほぼ毎回〜隔回で出現（R01〜R07の11回中7回）

**出題パターン**:

- 発電出力・年間発電量の計算
- 揚水発電の総合効率計算
- 有効落差の変化に伴う出力変化

**計算テンプレート**:

```
発電出力:  P = 9.8 × Q × H × η  [kW]
揚水入力:  P = 9.8 × Q × H / η  [kW]

総合効率（発電+揚水サイクル）:
  η_total = η_発電 × η_揚水

年間発電量:
  E = P × 設備利用率 × 8760 [kWh]
```

!!! note "有効落差Hの考え方"
    有効落差 = 総落差 - 損失落差（管路摩擦・弁損失など）
    問題文に「損失水頭○m」とあれば総落差から引く。

---

### 4位：変圧器（効率・負荷分担）

**出題頻度**: B問題（問15〜17）の枠内で11回中3回程度。並行運転の負荷分担や全日効率の計算が中心

**出題パターン**:

- 全日負荷曲線による1日の効率・損失エネルギー計算
- 2台並行運転時の負荷分担
- 最大効率時の負荷率計算

**計算テンプレート（効率）**:

```
全日効率 = 全日出力エネルギー / 全日入力エネルギー

全日出力エネルギー = Σ(P_出力 × 時間)
全日入力エネルギー = Σ(P_出力 × 時間) + 鉄損 × 24h + Σ(銅損 × 負荷率² × 時間)

最大効率条件: 鉄損 P_i = 銅損 P_c
最大効率時の負荷率: m = √(P_i / P_cn)
  ※ P_cn = 定格銅損（全負荷時の銅損）
```

**計算テンプレート（並行運転負荷分担）**:

```
2台の変圧器A・Bが並行運転するとき:
  I_A : I_B = (1/%Z_A) : (1/%Z_B) = %Z_B : %Z_A
              ↑ インピーダンスが小さい方に多く電流が流れる

担当容量:
  P_A = P_total × %Z_B / (%Z_A + %Z_B)
```

!!! warning "負荷分担の方向を間違えやすい"
    インピーダンスが**小さい方が多く電流を引き受ける**。
    直感と逆になりやすいので注意。理由：並列回路では抵抗が小さい方に電流が集まる。

---

### 5位：架空送電線路

**出題頻度**: A問題・B問題を合わせた計算系論点として11回中9回。B問題（問15〜17）への登場は不定期だが、A問題側（問11等）の論説・穴埋を含めると頻出

**出題パターン**:

- 電線のたるみ（弛度）計算
- コロナ発生限界電圧
- 中性点接地方式と故障時電圧・電流

**計算テンプレート（弛度）**:

```
弛度 D = wS² / (8T)
  w: 電線単位長さあたりの荷重 [N/m]
  S: 径間 [m]
  T: 電線の水平張力 [N]

電線長 L = S + 8D²/(3S)  (近似式)
```

---

### 6位：保護継電器・開閉装置

**出題頻度**: B問題（問15〜17）での計算出題はなく、保護継電器の計算はR01問8（A問題枠）の1回のみと極めて稀。中心はA問題（問6〜8に分散）の論説・穴埋で、そちらはR04下・R05下・R07下を除く8/11で出題（固定枠ではない）

**出題パターン**:

- 各継電器の役割と動作条件
- CB・DSの操作手順
- 変流器（CT）・計器用変圧器（VT）の役割

B問題としては計算よりも**知識問題に近い**出題が中心（過去に出た計算はR01の1回のみ）で、出た場合は得点しやすい部類。

## 時間配分

| フェーズ | 時間 | 内容 |
|---------|------|------|
| 着手順決定 | 5分 | 3問（問15〜17）を流し読みし、着手順を決める |
| B問題解答 | 45〜55分 | 1問15〜17分 |
| A問題見直し | 残り時間 | マークミス確認・未解答の再挑戦 |

!!! note "1問の時間内訳（15分）"
    - 問題読込・方針確認: 3分
    - 計算実行: 8分
    - 検算・単位確認: 4分

---

## 後回し（着手順）の判断基準

3問とも必答なので完全に捨てることはできない。以下の条件が重なる問題は後回しにし、得点しやすい問題を先に確保する:

1. **計算ステップが4段階以上**かつ途中で条件変換が必要
2. **見慣れない系統構成**（T分岐+ループなど複合系統）
3. **問題文が長く条件整理に5分以上かかりそう**

後回しを決めたら、まず取りやすい問題から確実に得点する。難問は最後に回し、完答できなくても小問aや途中式で部分点を取りにいく。1問に固執して時間を溶かすのが最悪パターン。

## 計算ミス防止チェックリスト

問題を解き終えたら、提出前に以下を確認する:

- [ ] 単位が揃っているか（[kW]・[W]の混在、[kV]・[V]の混在）
- [ ] 三相か単相かに応じた係数（√3 or 2）を使っているか
- [ ] sinΦを正しく計算したか（cosΦとsinΦを取り違えていないか）
- [ ] 求めたのが「送電端」か「受電端」か問題と一致しているか
- [ ] 効率η: 出力側はηを掛け、入力側はηで割っているか
