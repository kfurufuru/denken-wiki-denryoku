# B問題得点戦略

電力科目B問題（計算問題）の出題パターンと解法テンプレートをまとめる。
本ページの目的は「手が動く」レベルまでパターンを定着させること。

---

## B問題の基本構造

| 項目 | 内容 |
|------|------|
| 問題番号 | 問11〜問17（7問出題） |
| 選択数 | **5問選択**（2問は捨てられる） |
| 各問配点 | 6点（小問a=2点、b=4点が多い） |
| B問題合計 | **30点** |
| 目標得点 | 18点（選択5問中3問完答＋2問部分点） |

!!! note "選択戦略"
    事前に「得意3問・許容2問・捨て2問」を決めておく。
    試験当日に悩む時間を消費しないことが重要。
    得意分野がない場合は、計算ステップ数が少ない問題を優先する。

## 最頻出テーマ別：出題傾向と配点

### 1位：配電線路（電圧降下・電力損失）

**出題頻度**: ほぼ毎年（R01〜R06全て出題）

**出題パターン**:

- 負荷が末端に集中している単純な系統
- 途中に分岐がある系統（合成抵抗・合成電流の計算）
- 力率改善前後の比較

**計算テンプレート**:

```
Step 1: 負荷電流を求める
        I = P / (√3 · V · cosΦ)    [三相の場合]
        I = P / (V · cosΦ)          [単相の場合]

Step 2: 電圧降下を求める
        v = √3 · I(R·cosΦ + X·sinΦ)  [三相3線式]
        v = 2I(R·cosΦ + X·sinΦ)      [単相2線式]

Step 3: 電力損失を求める
        P_loss = 3I²R               [三相]
        P_loss = 2I²R               [単相2線]

Step 4: 送電端電圧 or 受電端電圧を求める
        Vs = Vr + v  (受電端基準)
        Vr = Vs - v  (送電端基準)
```

!!! warning "よくある計算ミス"
    - sinΦの計算忘れ: cosΦ=0.8 → sinΦ=0.6、cosΦ=0.6 → sinΦ=0.8（3-4-5の直角三角形）
    - 抵抗Rの単位: [Ω/km]なら線路長[km]を掛けることを忘れない
    - 三相と単相の係数（√3 vs 2）を取り違える

---

### 2位：変圧器（効率・負荷分担）

**出題頻度**: 3年に2回程度

**出題パターン**:

- 全日負荷曲線による1日の効率・損失エネルギー計算
- 2台並行運転時の負荷分担
- 最大効率時の負荷率計算

**計算テンプレート（効率）**:

```
全日効率 = 全日出力エネルギー / 全日入力エネルギー

全日出力エネルギー = Σ(P_出力 × 時間)
全日入力エネルギー = Σ(P_出力 × 時間) + 鉄損 × 24h + Σ(銅損 × 負荷率² × 時間)

最大効率条件: 鉄損 P_i = 銅損 P_c
最大効率時の負荷率: m = √(P_i / P_cn)
  ※ P_cn = 定格銅損（全負荷時の銅損）
```

**計算テンプレート（並行運転負荷分担）**:

```
2台の変圧器A・Bが並行運転するとき:
  I_A : I_B = (1/%Z_A) : (1/%Z_B) = %Z_B : %Z_A
              ↑ インピーダンスが小さい方に多く電流が流れる

担当容量:
  P_A = P_total × %Z_B / (%Z_A + %Z_B)
```

!!! warning "負荷分担の方向を間違えやすい"
    インピーダンスが**小さい方が多く電流を引き受ける**。
    直感と逆になりやすいので注意。理由：並列回路では抵抗が小さい方に電流が集まる。

### 3位：水力発電（出力計算・揚水）

**出題頻度**: 2〜3年に1回

**出題パターン**:

- 発電出力・年間発電量の計算
- 揚水発電の総合効率計算
- 有効落差の変化に伴う出力変化

**計算テンプレート**:

```
発電出力:  P = 9.8 × Q × H × η  [kW]
揚水入力:  P = 9.8 × Q × H / η  [kW]

総合効率（発電+揚水サイクル）:
  η_total = η_発電 × η_揚水

年間発電量:
  E = P × 設備利用率 × 8760 [kWh]
```

!!! note "有効落差Hの考え方"
    有効落差 = 総落差 - 損失落差（管路摩擦・弁損失など）
    問題文に「損失水頭○m」とあれば総落差から引く。

---

### 4位：架空送電線路

**出題頻度**: 2〜3年に1回

**出題パターン**:

- 電線のたるみ（弛度）計算
- コロナ発生限界電圧
- 中性点接地方式と故障時電圧・電流

**計算テンプレート（弛度）**:

```
弛度 D = wS² / (8T)
  w: 電線単位長さあたりの荷重 [N/m]
  S: 径間 [m]
  T: 電線の水平張力 [N]

電線長 L = S + 8D²/(3S)  (近似式)
```

---

### 5位：保護継電器・開閉装置

**出題頻度**: 不定期（2〜4年に1回）

**出題パターン**:

- 各継電器の役割と動作条件
- CB・DSの操作手順
- 変流器（CT）・計器用変圧器（VT）の役割

計算よりも**知識問題に近い**ため、B問題の中では得点しやすい部類。

## 時間配分

| フェーズ | 時間 | 内容 |
|---------|------|------|
| 問題選択 | 5分 | 7問を流し読みし、5問を選択 |
| B問題解答 | 75〜85分 | 1問15〜17分 |
| A問題見直し | 残り時間 | マークミス確認・未解答の再挑戦 |

!!! note "1問の時間内訳（15分）"
    - 問題読込・方針確認: 3分
    - 計算実行: 8分
    - 検算・単位確認: 4分

---

## 捨て問の基準

以下の条件が重なる問題は後回し・または捨てを検討する:

1. **計算ステップが4段階以上**かつ途中で条件変換が必要
2. **見慣れない系統構成**（T分岐+ループなど複合系統）
3. **問題文が長く条件整理に5分以上かかりそう**

捨て問を決めたら迷わず次の問題へ。取りにいって時間を溶かすのが最悪パターン。

## 計算ミス防止チェックリスト

問題を解き終えたら、提出前に以下を確認する:

- [ ] 単位が揃っているか（[kW]・[W]の混在、[kV]・[V]の混在）
- [ ] 三相か単相かに応じた係数（√3 or 2）を使っているか
- [ ] sinΦを正しく計算したか（cosΦとsinΦを取り違えていないか）
- [ ] 求めたのが「送電端」か「受電端」か問題と一致しているか
- [ ] 効率η: 出力側はηを掛け、入力側はηで割っているか
