## 電力科目の基本構造

- **A問題（問1〜10）**: 各5点 × 10問 = 50点。理論・定義・現象の理解
- **B問題（問11〜17の中から5問選択）**: 各6点（小問a=2点・b=4点の組が多い） × 5問 = 30点
- **合格ライン目安**: 60点（満点80点）

!!! note "得点戦略の基本方針"
    B問題5問を完走するより、**A問題10問を確実に取りきる**ことが優先。
    A問題で45点 + B問題で15点 = 60点という現実的な積み上げルートが安定する。

## 学習フェーズとドキュメントの使い方

```
[基礎期] テーマ別ページで公式の因果理解 → 引っかけパターン集で弱点確認
[演習期] B問題戦略で計算テンプレート定着 → 過去問マッピングで出題傾向把握
[直前期] 直前3日チェックリストに従って最終確認
```
