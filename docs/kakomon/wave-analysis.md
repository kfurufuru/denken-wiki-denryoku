## 3. R08（2026年8月）出題予測

> 基準日: 2026年4月。R08上期は 2026年8月実施予定（R07下=2026/3の直後）。

!!! warning "予測の限界（参考程度に）"
    A問題はテーマが問番号に固定されており「毎年出る」が実態（§1参照）。以下の★は「そのテーマ内でどの角度・形式が出るか」の読みにすぎず、統計的根拠は限定的。「◯年空白だから次は出る」型の推論は外れうる前提で、**★に関係なく頻出計算3本柱（配電・水力・火力）を仕上げるのが本筋**。

### 高確率（★★★）

| 論点 | 根拠 | 対策 |
|------|------|------|
| **配電 計算（電圧降下・変圧器過負荷）** | R01以降ほぼ毎回。R07上・下とも計算出題済みで手法が固定されている | 電圧降下公式・皮相電力→電流変換・変圧器並行容量の3パターンを完全習得 |
| **水力 計算（揚水発電・比速度）** | R07上（問15:調整池計算）・R07下（問2:運動エネルギー+問15未記載）と連続。B問題の柱 | 揚水効率（モータ入力）・発電機出力・有効落差の計算フローを固める |
| **火力 熱効率計算（重油消費・CO₂）** | R07上・R07下で連続出題（R06上は論説のみ）。直近2回連続はパターン固定の証拠 | 熱効率η＝出力/(燃料×発熱量)・CO₂換算（炭素比）の2式を軸に計算フロー完成 |

!!! note "B問題得点計画（R08版）"
    B問題（問15〜17）は3問必答・各10点・計30点満点。「配電計算・水力計算・火力計算（★★★）」がそのままB問題3問に対応するため、3問完答できれば30点。電気材料（問14:論説）はA問題で5点確定。これらを軸に、B問題で18点以上（3問中1〜2問完答＋残り部分点）を最低ラインに設定し、A問題の積み上げで合格点（60点）を確保する。

!!! note "計算論点の頻度と準備方針"
    R04〜R07の8回分で「電気材料（問14・A問題論説）」は8/8で出題。配電計算は6/8。水力計算は5/8。この3テーマは「必ず得点源にする」前提で準備する。変圧器計算は4/8で2年に1回ペースのため準備しておく価値あり。地中計算（充電電流）は2/8で解法は簡単だが出題頻度が低い。B問題（問15〜17）は3問必答のため、出題されたテーマは選択の余地なく解く必要がある。

### 計算問題の典型フロー

| テーマ | 出題パターン | 使用公式 |
|--------|-----------|---------|
| 配電 電圧降下 | 末端負荷型・集中負荷型・ループ配電 | ΔV ≈ (PR + QX)/V または √3・I・(Rcosθ + Xsinθ)・l |
| 配電 変圧器容量 | 過負荷防止・並行運転・遮断器定格 | 並行容量比＝%Z逆比。遮断電流＝短絡容量/(√3・V) |
| 水力 揚水 | 電動機入力・揚程・流量・効率 | P_motor = ρgQH/(η_pump・η_motor)×10⁻³ [kW] |
| 水力 発電 | 出力・使用水量・有効落差 | P = 9.8ηQH [kW]、H=有効落差、η=総合効率 |
| 火力 熱効率 | 重油消費量・CO₂排出量・発電電力量 | η = 出力/(燃料量×発熱量)。CO₂ = 燃料量×C比×44/12 |
| 変圧器 並行 | 負荷分担・過負荷容量 | P₁/P₂ = (%Z₂・S₁)/(%Z₁・S₂) |
| 原子力 比較 | ウランvs重油の等エネルギー質量比 | m_ウラン = m_重油×発熱量重油/発熱量ウラン |

| R07 | 電力系統 安定度・送電容量（穴埋） | 電力系統 周波数制御・需給運用（論説） | 安定度→需給と角度を完全に変えて両方出題 |
| R07 | 水力 理論出力と単位（穴埋） | 水力 落差分類（穴埋）+ 運動エネルギー（計算） | 穴埋→計算へ難度アップ |
| R06 | 水力 衝動水車・ペルトン（論説） | 水力 水車・発電機・主変圧器の特徴（論説） | 水車種類→設備構成と視点を変化 |
| R05 | 火力 コンバインドサイクル特徴（論説） | 火力 速度調定率と出力変化（計算） | 定性→定量へ完全転換 |

!!! note "上期・下期の角度読み方針"
    同テーマが上期・下期に連続出題されることは頻繁に起きる（R07火力・R07電力系統など）。「上期で出たから下期は出ない」という読みは電力科目では危険。ただし**同一問題型（穴埋→穴埋）の連続は稀で、形式（論説→計算・計算→穴埋）を変えてくることが多い**。R07下で計算型が多かった分野（配電・火力）はR08でも計算型継続の可能性が高い。

## 6. 攻略戦略まとめ

### R08直前の優先順位

| 優先度 | テーマ | 期待点数 | 目標 |
|--------|--------|--------|------|
| **P1（必須）** | 配電計算（電圧降下・変圧器容量） | 10点（B問題1問） | 計算フロー3パターンを反射的に出せるまで |
| **P1（必須）** | 水力計算（揚水・発電出力） | 10点（B問題1問） | ηQH公式と揚水公式の単位換算まで完全習得 |
| **P1（必須）** | 火力計算（熱効率・CO₂排出量） | 10点（B問題1問） | η式とCO₂換算（44/12係数）の2式固定 |
| **P1（必須）** | 電気材料（問14:論説） | 5点（A問題・問14） | 導体・絶縁体・磁性体・SF6の基本特性を整理 |
| **P2（準必須）** | 変圧器計算（B問題） | 10点（B問題1問） | 並行運転の%Z比と遮断電流計算の2式 |
| **P2（準必須）** | 水力・火力・原子力（A問題穴埋） | 各2〜5点 | キーワード（比速度・コンバインド・軽水炉）定義の正確な理解 |
| **P3（余裕があれば）** | 架空送電・地中送電・開閉装置（A問題） | 各5点 | 論説の定性理解。計算は出ても1問止まり |
| **P3（余裕があれば）** | 電力系統（問10） | 5点 | 安定度・需給・中性点接地の3テーマを網羅 |

!!! warning "時間配分の優先判断"
    試験2週間前時点で P1（4テーマ）が完成していない場合、P3に着手するより P1の完成度を上げることを優先する。P1の4テーマ（B問題の計算3問＝30点＋電気材料5点）だけで理論上35点が確保でき、加えてA問題（問1〜14・各5点）で5問正答すれば計60点（合格圏内）になる。

### なぜ出題周期があるのか（因果説明）

出題実績から確認できる構造的事実は2つ。

1. **問番号とテーマの固定配置**: 問1=水力、問4=原子力、問14=電気材料という配置がR01〜R07の全回で観測されている。周期ではなく「テーマは固定・角度のみ変わる」という構造。

2. **計算テーマのローテーション**: B問題（問15〜17）は3問必答で、配電・水力・火力の計算が高頻度、変圧器・地中が低頻度で入れ替わる傾向が実績上観測される。ただしローテーションの理由は外部から検証できず、「空白期間が長いほど次に出やすい」という保証はない。
