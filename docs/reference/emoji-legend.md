# 標準セクション構成ガイド

各テーマページはおおむね次の共通セクション構成で書かれている。絵文字マーカーはこの構成の目印として見出しに使われることがある。

| セクション | 絵文字 | 内容 |
|-----------|--------|------|
| 1. 直感的理解 | 🧠 | 「水流＝電流」のような比喩・本質の一言 |
| 2. 設備を歩く | 🏭 | 設備フロー図・主要機器の役割 |
| 3. 比較表 | ⚖️ 🔬 | 類似設備・方式の違いを表で整理（最重要マーク付きが多い） |
| 4〜5. 公式マップ | 🔍 🧮 | 公式の意味・導出・使える条件（レイヤーA/B構成） |
| 解法パターン | 🛤️ | 計算問題の「型」＋例題（見分け方→手順→落とし穴） |
| 引っかけパターン | 🕳️ 💡 | 間違えやすいポイントの因果説明 |
| 正誤判定の急所 | 📝 ⚡ | 正誤問題でよくある誤文と判定根拠 |
| 出題実績 | 📊 | 年度別の出題記録＋[過去問マッピング](../kakomon/index.md)への横断リンク |

## 本文中の補助マーカー

| 絵文字 | 意味 |
|--------|------|
| 🎯 | 重要ポイント・合格基準対応ナビ |
| ⚡ | 5秒で思い出す（速攻暗記フレーズ） |
| 😱💀🔥💥 | 事故・危険（安全に関わる重大事項） |

## 使い方

- 初見のテーマ → 1（直感）→ 3（比較表）→ 公式マップ の順に読む
- 直前期 → 引っかけパターンと正誤判定の急所だけをスキャン
- 計算対策 → 解法パターンの例題を手を動かして解く
